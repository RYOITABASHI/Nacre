# person_names.tsv — provenance and method

`person_names.tsv` is generated by `tools/dict/generate_person_names.py`.
Do not edit it by hand; edit the source lists in that script and re-run it.

## Why this file exists

`NacreDictionary` has always tried to load `dict/person_names.tsv` as a
supplementary dictionary, but the file was never committed, so the load
silently skipped it ("No person names dictionary found (optional)") and
person names relied entirely on whatever the Mozc base dictionary happened
to contain. Common full names converted poorly as a result — e.g. in the
210-sentence conversion benchmark, たなかたろう → 田中太郎 was absent from
the candidates entirely and すずきいちろう → 鈴木一郎 ranked 14th.

## Contents (98,812 entries)

| Section | Entries | POS (Mozc ID) | Base cost |
|---|---|---|---|
| Surnames | 257 | 1923 （姓） | 4500 |
| Given names | 381 | 1922 （名） | 5000 |
| Full names (surname × given) | 98,174 | 1921 （人名） | 4000 |

Format: `reading<TAB>surface<TAB>left_id<TAB>right_id<TAB>cost`, UTF-8 —
exactly what `NacreDictionary.loadSupplementaryDict` parses. POS IDs and
base costs follow the convention of the earlier (never shipped)
JMnedict-based generator in `.github/workflows/build-person-names.yml`.
At load, `NacreDictionary` subtracts 1500 from entries with POS 1921–1923
and cost > 3500, so effective costs are 2500 / 3500 / 3000.

## Sources (all published, factual name data)

- **Surnames** — the national surname ranking published by 名字由来net
  (Rixsta), based on government statistics and telephone-directory data.
  The top 100 are included in published order (verified against the
  October 2026 update: 佐藤 ≈1.78M people, 鈴木 ≈1.73M, 高橋 ≈1.35M, …),
  followed by the ranking's commonly published next band (~101–300).
  Each surname carries its dominant published reading; a second entry is
  added where another reading is also common （山崎 やまさき, 河野 かわの,
  藤原 ふじはら, 高田 たかた, 長田 ながた).
- **Given names** — names topping the baby-name surveys published annually
  by Meiji Yasuda Life （赤ちゃんの名前調査， running since 1989; 表記 and
  読み方 rankings), pooled across eras so the list covers living adults
  （太郎・花子・一郎・健一 …) as well as recent children （陽翔・紬・凛・湊）.
  Multiple published spellings per reading and multiple common readings
  per spelling are kept as separate entries.
- **Full names** — composed programmatically: every surname × every given
  name, reading = surname reading + given reading. Composition is what
  lets a typed full name convert in one shot.

Names and their readings are facts; no copyrighted text is reproduced.
Attribution is also recorded in `THIRD_PARTY_LICENSES.md`.

## Privacy rule

Only generic, nationally common names from the published rankings above
are included. No individual's name — including the repository owner's —
was added by hand, and no personal data (contacts, family, address-book
names) is in this file. Names that are not nationally common do not
appear, by design.

## Size

4.7 MB of TSV in the repository. `.tsv` assets are deflate-compressed by
aapt when packaging (only `gz`/`tsv.gz` are listed in `noCompress`), so
the packaged cost is ≈0.6 MB (the gzip -9 size of this file), in line with
the other bundled dictionaries.

| overall top-1 | 19.0% | 21.4% |
| overall top-3 | 35.2% | 37.1% |
| overall MRR | 0.293 | 0.313 |
| names top-1 | 13.6% | 36.4% |
| names top-3 | 45.5% | 63.6% |
| names MRR | 0.310 | 0.506 |

All other categories (daily, homophone, loanword, long, numeric) are
unchanged. Person-name rows: 田中太郎 absent→1st, 鈴木一郎 14th→1st,
佐藤健二 absent→1st, 山田花子 3rd→1st, 中村明 8th→1st.
